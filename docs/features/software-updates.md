# Software Updates

## Purpose

Help users keep Pingo current from within the app.

## User Story

As a user, I want Pingo to check for updates so that I can install new versions when they are available.

## Acceptance Criteria

- Pingo checks for updates automatically when automatic checks are enabled.
- The menu bar window provides a manual update check.
- The manual check is unavailable while an update check cannot be started.
