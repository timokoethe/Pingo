# HTTP Method Selection

## Purpose

Let users choose the HTTP operation needed for a request.

## User Story

As a user, I want to select an HTTP method so that I can test different endpoint operations.

## Acceptance Criteria

- The request editor offers `GET`, `POST`, `PUT`, `PATCH`, and `DELETE`.
- The selected method is used when the request is sent.
