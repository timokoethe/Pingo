# Menu Bar Access

## Purpose

Keep the API scratchpad available without opening a regular app window.

## User Story

As a user, I want to open Pingo from the menu bar so that I can make a quick request without leaving my current workflow.

## Acceptance Criteria

- Pingo appears in the macOS menu bar while it is running.
- Selecting the menu bar icon opens the scratchpad.
- The menu bar window provides a control to quit Pingo.
